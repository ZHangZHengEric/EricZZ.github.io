Sage

Recursive Self-Improvement (RSI)

Sage 是我创建并维护的开源 Agent 项目。目前主要研究递归自我改进（RSI），包括如何利用任务反馈改进智能体的指令与技能，以及如何评估这些改动的有效性。

Sage is an open-source agent project that I created and maintain. My current focus is recursive self-improvement (RSI): using task feedback to refine agent instructions and skills, and evaluating whether these changes are effective.

系统包含任务执行、独立评测和版本比较。训练反馈用于调优，固定验证集用于选择候选，独立测试集用于观察结果。实现、实验记录及目前的局限见项目介绍。

The system supports task execution, independent evaluation, and version comparison. Training feedback guides refinement, a fixed validation set selects candidates, and independent tests measure outcomes. Implementation details, experiment records, and current limitations are described on the project page.
